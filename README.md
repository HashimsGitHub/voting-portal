## 👤 What Can I Do With Each Account?

### As a Voter
1. Log in with the voter account.
2. Go to the election page and browse the list of candidates.
3. Click **Vote** next to the candidate you support for each seat.
4. Confirm your choice — your vote is final once submitted.
5. You can only vote once per seat, so choose carefully.

### As a Candidate
1. Log in with the candidate account.
2. Go to **My Profile**.
3. Fill in your bio, upload a photo, and add any social/campaign links.
4. Select the seat(s) you want to run for (up to 3).
5. Once the admin starts the election, your seat selection locks — so make your choice before then.

### As an Admin
1. Log in with the admin account and open the **Admin Dashboard**.
2. Under **Positions/Seats**, create the seats candidates can run for (e.g. President, VP East Region).
3. Use the three election controls, in order:
   - **Allow Candidates to Select Seats** — candidates can pick which seat they're running for.
   - **Start Election** — seat selection locks, and voters can begin voting.
   - **Stop Election** — voting closes and results are final.
4. You can also review and correct any candidate's details or seat assignment from the dashboard at any time.

## ❓ Need Help?

If something isn't working as expected, or a vote doesn't seem to register, please contact the election administrator directly rather than trying again multiple times, so a real vote doesn't get miscounted.
