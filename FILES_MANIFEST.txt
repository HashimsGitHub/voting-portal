CUSTOMIZATION GUIDE
================================================================================

TO CHANGE NUMBER OF SEATS:
  1. In AdminDashboard.jsx: Change default value in form
  2. Or in election.py: Change `total_seats: int = 10`
  3. Set when creating new election (fully flexible)

TO CUSTOMIZE COLORS:
  1. Open frontend/src/styles/main.css
  2. Modify CSS variables in :root section
  3. --primary-color, --secondary-color, etc.

TO ADD CUSTOM FIELDS:
  1. Add to Candidate model in api/models/election.py
  2. Update database operations in election_repository.py
  3. Add form fields in frontend CandidateProfiles.jsx

TO ADJUST AUTO-REFRESH:
  1. Open frontend/src/pages/LiveResults.jsx
  2. Change `setInterval(fetchResults, 5000)` to desired ms
